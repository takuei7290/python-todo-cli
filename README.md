# python-todo-cli

シンプルなToDo/メモ管理CLIツール。Python学習用のプラクティスプロジェクト。

## 機能

- **追加 (add)**: タスクを新規登録する
- **一覧 (list)**: 全タスクを表示する(完了したタスクには印をつけて区別)
- **完了 (done)**: idを指定してタスクを完了状態にする(一覧からは消えない)
- **削除 (delete)**: idを指定してタスクを削除する(削除前に確認メッセージを表示)

## データ項目

各タスクは以下の情報を持つ。

- id(自動採番)
- 内容(タスクの文字列)
- 完了フラグ(初期値: 未完了)
- 作成日時

## データ保存

JSONファイルに保存し、プログラム終了後もデータを保持する。
